# IA 4 — Planning Intelligent

## 1. Objectif

Le module Planning Intelligent aide les RH à choisir les meilleurs créneaux pour organiser un événement interne.

Il analyse l’historique CapEvents afin d’estimer les créneaux les plus favorables selon :

- la catégorie ;
- le département ciblé ;
- le jour ;
- l’heure ;
- la durée ;
- le format ;
- la capacité ;
- l’historique de participation ;
- les conflits avec d’autres événements.

## 2. Principe

Le module ne crée pas automatiquement l’événement.

Il propose des créneaux classés, puis le RH choisit.

```txt
IA propose
RH valide
Spring Boot crée ou modifie l’événement
